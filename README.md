# DataFarm SensorData API

## View the Code-Generated API Documentation [here](https://api.datafarm.co.za/v1/docs).

This API is used to make SensorData available to DataFarm clients. With this project, Data Availability is our main concern so there is an ongoing effort to manage potential breaking changes. This is done through CI and more specifically Github Actions and Workflows on this repository.

If you are interested in contributing, it is recommended to familiarise yourself with the tests/api_test.go file first.

Any further questions are welcome and to be directed to [Geraud](mailto:geraud@datafarm.co.za?subject=DataFarm%20API%20Contributing).
